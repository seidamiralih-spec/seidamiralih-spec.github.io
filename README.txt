مراحل آپلود در GitHub:
1) این فایل ZIP را در لپ‌تاپ Extract کنید.
2) وارد پوشه birthday_site_github_pages شوید.
3) تمام محتویات داخل این پوشه را انتخاب کنید (خود پوشه را انتخاب نکنید).
4) در مخزن GitHub، از Add file > Upload files استفاده کنید.
5) فایل‌ها و پوشه images را در ریشه مخزن رها کنید و Commit changes را بزنید.
6) در Settings > Pages، گزینه Deploy from a branch را انتخاب کنید.
7) Branch را main و Folder را /(root) قرار دهید و Save کنید.

نکته مهم عکس‌ها:
عکس‌های شخصی شما در فایل‌های ارسالی این نوبت وجود نداشتند؛ بنابراین پوشه images خالی است.
چهار عکس را با نام‌های دقیق زیر داخل images قرار دهید:
photo1.jpg
photo2.jpg
photo3.jpg
photo4.jpg

اگر عکس‌ها فرمت دیگری دارند، نام و پسوندشان را مطابق srcهای داخل gallery.html تغییر دهید.
فایل index.html باید مستقیماً در ریشه مخزن باشد، نه داخل یک پوشه اضافی.
